# 声笺 1.4：免密钥电脑加速、状态显示

开发进展、部署核查和接续步骤以项目根目录 [PROJECT_STATUS.md](../../PROJECT_STATUS.md) 为准；本文件用于用户安装与升级。

镜像：`shengjian:1.4.0-arm64`，用于极空间 Z2 Pro。模型已经内置。电脑端复用当前 Windows 的 FunASR 与 RTX 5080，音频经局域网传输。

## 升级已有容器

1. 等现有任务完成，或在升级前妥善保留其上传文件；记下原 `/data` 对应的 NAS 文件夹。
2. 导入包内 `shengjian-z2pro-arm64.tar`，使用镜像 `shengjian:1.4.0-arm64` 更新或重新创建声笺容器。
3. 继续挂载同一个原数据文件夹到 `/data`，读写。保持 bridge 网络、NAS `18088` → 容器 `8787`、自动重启，建议 2 核和 2GB。
4. 保留原来的 `ACCESS_CODE` 网页口令。手动创建时，只需要填写这一个必填环境变量。
5. 启动后刷新网页并登录即可。**不再需要导入任何电脑配置文件或密钥**：任务开始时自动检测电脑，只要电脑开机并运行转写服务，就默认用电脑 GPU 转写；电脑关机或不可用时自动改用 NAS CPU。网页“电脑加速”卡片实时显示电脑在线/离线状态。

从 1.2/1.3 升级：旧版网页里保存过的连接设置会继续使用其中的电脑地址，旧密钥字段会被忽略；也可以在网页“电脑地址设置”中重新保存一次地址来清掉旧密钥。旧参数 `REMOTE_WORKER_URL` 仍兼容（作为默认地址），`REMOTE_WORKER_TOKEN` 不再使用。

## 为什么不再需要密钥

声笺只在内网使用，且只有一位用户。1.4 起电脑 GPU 服务不再校验连接密钥，NAS 与电脑之间也不再有密钥配置。电脑服务的入站访问仍由 Windows 防火墙限制在本地子网内。网页访问口令 `ACCESS_CODE` 保持不变，它保护的是手机/浏览器入口，与电脑服务无关。

## 访问地址

- 局域网网页：`http://192.168.1.66:18088`。
- Tailscale 网页：`http://100.114.153.9:18088`。
- NAS 调用电脑：`http://192.168.1.73:18788`，音频不经过 Tailscale。

电脑服务及登录自启已在当前电脑配置。原来的 Windows 防火墙放行规则可继续使用。

## 电脑检测与回退

任务开始前检查电脑识别服务是否就绪，就绪即默认使用电脑 GPU，无需任何操作。网页“电脑加速”卡片每 15 秒左右自动刷新在线状态；只有电脑 IP 变化时才需要在“电脑地址设置”中修改地址并保存，修改对下一条开始的任务生效，不打断当前任务。

电脑端口拒绝连接、连接超时、电脑正忙、GPU 显存不足、模型加载中、电脑任务出错或处理中断都会给出具体原因，随后使用 NAS CPU。不会自动唤醒电脑。

建议在路由器做 DHCP 地址保留：NAS `192.168.1.66`、电脑 `192.168.1.73`。防火墙规则默认允许 LocalSubnet，因此 NAS 在同一子网内换地址不会被旧的单一 IP 规则拦截。

## 任务日志

NAS 容器日志会输出任务名称、任务 ID、开始时间、执行设备、识别引擎、没有使用电脑的原因、完成耗时及文件清理结果。移除了彩色控制字符，避免日志界面出现乱码。

网页每条记录中也有“任务日志”，可以查看接收、开始、设备检测、执行、回退、完成、终止和清理事件。日志内时间带 `+04:00` 时区，网页时间按当前设备时区显示。

旧任务保留原来的转写结果，但无法补造未记录过的详细日志；新日志从升级后的任务开始记录。

## 终止任务

选中任务后点击“终止”：

- 排队任务直接取消并删除上传音频。
- 处理中先显示“终止中”，停止转换或识别并清理 NAS 临时文件后显示“已终止”。
- 电脑 GPU 任务也会收到取消通知，在模型运算边界停止并清理电脑临时文件。单次已提交的运算需要短暂结束，因此可能稍等片刻。
- 已终止任务保留记录和日志，可再点击“删除”。本版不提供暂停或断点恢复。
- 电脑离线时无法立即删除其磁盘文件；NAS 会清理自己的文件，电脑残留在下次服务启动时清理，页面会说明此情况。

正常转写完成或失败后，两端临时音频同样会删除。文字记录保留 7 天。最大音频 300 MB、最长 3 小时，不调用手机麦克风。

## Compose

将 `compose.yaml`、`nas.env` 放在同一个项目目录。升级旧服务时，在项目旁 `.env` 写入 `ATOW_DATA_DIR=原来挂载到/data的NAS绝对路径`，避免误用新的空目录。导入镜像后可通过极空间 Compose 启动，也可执行 `sh install.sh`。

只需要 `nas.env` 里的 `ACCESS_CODE`。电脑地址默认已内置，无需其他环境变量；后续更新容器时继续挂载原 `/data` 即可保留改动过的设置。

## 验证范围

已使用 ARM64 模拟 NAS 调用真实 RTX 5080，验证零配置 GPU 转写、具体回退原因、网页状态显示、重启后配置保留、任务日志、取消排队任务、取消正在识别的 NAS CPU/GPU 任务、音频清理，以及终止后的下一条 GPU 任务。模拟环境的速度不代表 Z2 Pro 实机速度。

NAS 主机的容器仍需按上述步骤升级；安装包不会自动修改 NAS。
