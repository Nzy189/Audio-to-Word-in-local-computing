# Windows RTX 5080 转写服务

开发进展和实际运行核查以项目根目录 [PROJECT_STATUS.md](../PROJECT_STATUS.md) 为准；本文件用于电脑服务管理。

现有 FunASR 环境：`F:\Claude Code Project\DeepTutor\FunASR\.venv`。本服务复用该环境中的 PyTorch CUDA 和 FunASR，不需要修改它的依赖。模型使用已有的 SenseVoiceSmall 与 FSMN VAD 缓存。

工作地址为 `http://192.168.1.73:18788`，供 NAS 的后台访问，不是给手机打开的网页。手机继续打开 NAS 的 `18088` 端口。

## 当前配置

- 1.4 起本服务不再校验连接密钥：内网单人使用，NAS 直接访问。`worker.env` 中旧的 `WORKER_TOKEN` 行已不再被读取，可留可删；入站访问仍由 Windows 防火墙限制在本地子网。
- 程序日志和临时任务位于 `%LOCALAPPDATA%\ShengjianWorker`。
- GPU 每次只处理一条任务；模型未加载、CUDA 不可用、空闲显存不足或者已有任务时，NAS 会使用自己的 CPU。
- 当前源码动态批次预算为 `batch_size_s=300`，保留 FP32、15 秒合并片段、30 秒 VAD 最长片段与原取消/清理机制。`/v1/health` 返回实际批次预算和模型精度；保存源码后需在服务空闲时重启才生效。现有发布包中的 worker 不会随源码修改自动更新。
- 程序不会唤醒关机电脑，也不会更改睡眠设置。电脑休眠、关机或服务退出时，由 NAS 自动回退。

## 启动和自启

运行 `start-worker.ps1` 可在后台启动；若 FunASR 位置不同，用 `-PythonExe` 指定虚拟环境中的 `python.exe`。

运行 `install-startup.ps1` 在当前用户的 Windows 启动文件夹创建快捷方式。此方式在登录 Windows 后启动，锁屏后仍可工作；尚未登录或者服务没有就绪时，NAS 使用本地 CPU。

启动文件夹中的快捷方式名为 `Shengjian GPU Worker.lnk`。删除该快捷方式即可取消登录自启。

## 放行 NAS 的局域网连接

在这台电脑上，右键 `allow-nas.cmd`，选择“以管理员身份运行”。它允许本地子网访问本机 TCP `18788`，NAS 的 DHCP 地址变化也不受影响，不会创建路由器公网端口转发。当前普通权限的工作进程无法直接添加 Windows 防火墙入站规则，因此提供此脚本由管理员执行。

如果 NAS 地址改变，可在管理员 PowerShell 中执行：

```powershell
.\allow-lan-firewall.ps1 -NasIp 新的NAS内网IP
```

建议在路由器中固定 NAS `192.168.1.66` 与电脑 `192.168.1.73` 的 DHCP 地址。

## 音频清理

接收的录音和转换后的 WAV 在处理结束时删除，不保留原音频。未完成上传立即清理；异常退出留下的音频在下次启动时删除，运行中也有定期清理。NAS 收到并保存结果后会确认任务，电脑随即删除结果元数据；未确认的文字结果最多保留一小时，音频已提前删除。

NAS 会保留自己的上传文件直到远程结果成功保存，或者本机回退转写结束，再删除原文件。因此电脑中途离线不会导致唯一一份录音丢失。

## 重启与 DHCP 地址变化

推荐在路由器的 DHCP 地址保留或静态租约中，按网卡 MAC 固定分配 NAS `192.168.1.66` 和电脑 `192.168.1.73`。设备仍自动获取地址，由路由器保持稳定。电脑 IP 改变时，在 NAS 网页的“电脑加速”中更新电脑地址；未更新期间自动使用 NAS CPU。防火墙默认按 LocalSubnet 放行，可覆盖 NAS 在同一局域网内的地址变化。

## 1.4 免密钥与终止

NAS 不再需要导入 `computer-connection.json` 或填写任何密钥：任务开始时自动检测本服务，在线即默认使用 GPU。电脑 API 保持相同地址与协议。取消 GPU 任务会在 PyTorch/VAD 模块边界中断，先等待已提交的运算结束，再删除临时音频；之后仍可接收新任务。
